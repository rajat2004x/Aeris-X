# AERIS-X

## Step 7: Classical ML baseline benchmark

The Step 7 benchmark uses the ML-ready arrays generated by Step 6 and does
not modify the preprocessing outputs. It flattens each temporal window only
in memory, fits models on `X_train.npy`/`y_train.npy`, and evaluates them on
the validation arrays.

Run it from the repository root:

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe scripts\run_step7_benchmark.py
```

The benchmark includes a mean RUL baseline, linear regression, and random
forest. XGBoost is included automatically when the optional `xgboost` package
is installed. Results, predictions, serialized models, and comparison plots
are written to `reports/experiments/step7_classical_ml/`.

Run the Step 7 tests with:

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe -m pytest tests\test_step7_benchmark.py -q
```

## Step 8: Temporal deep-learning benchmark

Step 8 benchmarks LSTM, GRU, TCN, and Transformer Encoder regressors on the
same leakage-safe temporal windows. Models preserve the `(batch, sequence,
features)` representation, use reproducible seed 42, and select CUDA
automatically when available while retaining CPU support.

Run it from the repository root:

```powershell
$env:PYTHONPATH = "src"
.\.venv\Scripts\python.exe scripts\run_step8_temporal_benchmark.py
```

Results, checkpoints, predictions, plots, configuration, and the experiment
report are written to `reports/experiments/step8_temporal_dl/`.
